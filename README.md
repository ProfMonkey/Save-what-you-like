# 🐒 收一下 · Save What You Like

一个以**本地优先、隐私优先**为核心的 Chrome / Edge 浏览器扩展。

它解决的是一个很简单的问题：

> 看到一篇值得留下的网页文章，点一下「收藏当前网页」，以后即使原网页暂时打不开，也可以在浏览器本地查看已经保存的文字和部分正文图片。

当前版本：**V0.3.0**

---

## ✨ 当前版本功能

### 1. 一键收藏当前网页

打开普通的 `http/https` 网页后，点击浏览器扩展按钮，再点击：

**「收藏当前网页」**

程序会读取当前页面并保存到本地。

保存的信息包括：

- 网页标题
- 网页 URL
- 正文文字
- 正文图片信息
- 本地保存时间

---

### 2. Mozilla Readability 正文提取

V0.3 使用本地集成的 **Mozilla Readability** 对网页进行正文提取。

相比直接读取整个网页，它会尽量：

- 去掉导航栏等无关内容
- 去掉大量页面 UI
- 提取主要文章正文
- 保留文章中的图片结构

如果 Readability 无法成功提取正文，程序会自动使用基础提取方式作为 fallback，而不是直接让整个收藏操作失败。

Readability 源码位于：

```
vendor/Readability.js
```

对应许可证文件：

```
vendor/READABILITY_LICENSE.md
```

---

### 3. 正文图片保存

程序会尝试识别正文中的图片，并将成功读取的图片保存到浏览器本地。

当前限制：

- 每篇文章最多处理 **20 张正文图片**
- 单张图片最大 **2 MiB**
- 图片必须能够被当前网页环境成功读取
- 某些网页的图片可能因为权限、跨域、懒加载或网站自身限制而无法保存

**图片保存失败不会阻止整篇文章的文字保存。**

---

### 4. 真正的本地离线图片

文字和文章元数据保存到：

```
chrome.storage.local
```

图片 Blob 保存到：

```
IndexedDB
```

因此已经保存成功的图片不依赖原网页继续在线存在。

收藏内容在扩展本地打开时，会重新读取 IndexedDB 中保存的图片并显示。

---

### 5. 本地收藏列表

扩展弹窗中会显示已经收藏的网页。

每条收藏包括：

- 标题
- 保存时间
- URL
- 「查看文字」
- 「删除」

点击「查看文字」后，可以展开已经保存的文章正文和成功保存的图片。

---

### 6. 同 URL 更新

如果再次收藏同一个 URL：

- 不会无限生成重复记录
- 新内容会替换旧的同 URL 收藏
- 最新保存时间会更新

---

### 7. 收藏数量限制

当前最多保存：

**30 篇网页**

超过限制后，程序会保留最新的 30 篇。

---

### 8. 正文长度限制

单篇文章正文最多保存：

**20,000 个字符**

这是为了避免极端网页占用过多本地存储。

---

## 🔒 隐私设计

这是项目的重要设计原则。

当前版本：

- ❌ 不需要账号
- ❌ 不需要服务器
- ❌ 不上传用户收藏内容
- ❌ 不建立云端数据库
- ❌ 不做用户行为追踪
- ✅ 收藏内容保存在当前浏览器本地
- ✅ 图片使用 IndexedDB 本地保存
- ✅ 尽量减少浏览器权限

扩展权限：

```text
activeTab
scripting
storage
unlimitedStorage
```

其中：

- `activeTab`：访问用户当前主动操作的网页
- `scripting`：在当前网页中执行正文和图片提取逻辑
- `storage`：保存收藏数据
- `unlimitedStorage`：为本地收藏提供更充足的浏览器存储空间

## 🚀 安装与运行

当前版本可以通过「加载已解压的扩展」运行。

### Chrome

在地址栏打开：

```
chrome://extensions/
```

### Edge

在地址栏打开：

```
edge://extensions/
```

然后：

1. 打开「开发者模式」
2. 点击「加载已解压的扩展」
3. 选择本项目文件夹
4. 浏览器工具栏中打开「收一下」
5. 打开一篇普通网页
6. 点击「收藏当前网页」
7. 在「本地收藏」中查看结果

详细说明见：

```
HOW_TO_RUN.md
```

## 🧠 技术方案

当前版本主要使用：

- JavaScript
- HTML
- CSS
- Chrome / Edge Extension API
- Manifest V3
- Mozilla Readability
- `chrome.storage.local`
- IndexedDB
- Blob / FileReader
- DOM Parser

整体结构坚持：

```
网页
 ↓
当前标签页读取
 ↓
Readability 正文提取
 ↓
文字 + 图片识别
 ↓
文字/元数据 → chrome.storage.local
图片 Blob → IndexedDB
 ↓
本地收藏列表
 ↓
离线阅读
```

## ⚠️ 当前限制

V0.3.0 仍然是第一轮可用原型，并不是最终产品。

目前还没有：

- ❌ 文件夹分类
- ❌ 搜索
- ❌ 导出
- ❌ 导入
- ❌ 云同步
- ❌ 账号系统
- ❌ 完整网页 HTML/CSS 排版还原
- ❌ 所有网站的图片兼容保证

特别是图片：

> 程序会尽可能保存正文图片，但无法保证所有网站的图片都能被读取和离线保存。

此外，目前仍需要继续进行不同 Chrome / Edge 网页场景下的兼容性测试，尤其是**关闭原网页、断网后重新打开收藏并确认文字和图片均可读取**的严格离线验收。
